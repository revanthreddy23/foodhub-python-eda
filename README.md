# 🍔 FoodHub Order Analysis & Customer Insights

## 📌 Project Overview

FoodHub is an online food delivery platform that connects customers with multiple restaurants.  
This project focuses on **analyzing FoodHub order data** to uncover **customer behavior, restaurant performance, and delivery trends**, enabling **data-driven business decisions**.

The analysis was performed using **Python, exploratory data analysis (EDA), and visualization techniques** to extract meaningful insights from real-world food delivery data.

---

## 🎯 Business Objective

The main goals of this project are to:

- Understand **customer ordering patterns**
- Identify **top-performing restaurants and cuisines**
- Analyze **delivery time and order value trends**
- Provide **actionable recommendations** to improve customer experience and operational efficiency

---

## 🧠 Key Questions Answered

- What are the **most popular cuisines and restaurants**?
- How does **delivery time impact customer ratings**?
- Which factors influence **higher order values**?
- Are there noticeable **peak ordering times**?
- How can FoodHub **optimize delivery and restaurant partnerships**?

---

## 📊 Dataset Description

The dataset contains order-level information such as:

- Order ID  
- Customer ratings  
- Food preparation and delivery time  
- Order cost  
- Cuisine type  
- Restaurant name  

*(Dataset used for academic and learning purposes)*

---

## 🔍 Approach & Methodology

1. **Data Understanding**
   - Checked structure, data types, and basic statistics
2. **Data Cleaning**
   - Handled missing values and inconsistencies
3. **Exploratory Data Analysis (EDA)**
   - Univariate and bivariate analysis
   - Visualizations using plots and charts
4. **Insights & Recommendations**
   - Business-focused interpretation of results

---

## 📈 Key Insights

- Certain cuisines consistently generate **higher order volumes**
- **Longer delivery times** tend to correlate with **lower customer ratings**
- A small group of restaurants contributes to a **large share of total revenue**
- Peak demand occurs during **specific time windows**, indicating staffing and logistics optimization opportunities

---

## 💡 Business Recommendations

- Partner more closely with **high-performing restaurants**
- Improve delivery logistics during **peak hours**
- Reduce preparation and delivery delays to improve **customer satisfaction**
- Design targeted promotions for **high-demand cuisines**
